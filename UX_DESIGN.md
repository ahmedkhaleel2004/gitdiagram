# UX Design and Behavioral Psychology Documentation

## 1. Target Users and Goals

### Target Users:

#### Fitness Lovers: Individuals passionate about working out and want to track their data effortlessly.

#### Busy Schedules: Those who aim to get fit but do not have much time and want to set up and track their logs fast and efficient.

### Goals:

#### Eliminate unnecessary effort and steps to log workouts.

#### Show clear and simple visual info after steps are completed.

#### Encourage the daily log-on habit of working out.

## 2. User Journey and Usability

### User journey:

#### i. Open the log workout screen

#### ii. See default sets and reps values

#### iii. Edit sets and reps or leave them

#### iv. Click highlighted save button to save the recommended values

### Quick stepper: Adding "+" and "–" buttons to get to the desired number without inputting it through input devices manually.

### Default values: Fill in sets and reps fields with the ones used in the previous workout

### Toast/animation: Show a brief message or animation that the workout was successfully saved.

## 3. Implemented Cognitive Biases

### Default bias:

#### People have biases for default options and require extra, seemingly unnecessary, effort to choose the other options and, therefore, does not pick said options. It can be seen when a user chooses the default sets and reps values. Instead of changing them, they would rather save time and effort.

### Von Restorff effect:

#### A person can better recollect an item that is singled out from the rest. The "save workout" button should stand out from the rest; hence, missing it should be impossible.
